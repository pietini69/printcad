# Security Policy

## Supported Versions
Only the latest release of PrintCAD is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability in PrintCAD, please send an email to niko.pietinen@gmail.com.
Reports are investigated promptly.
